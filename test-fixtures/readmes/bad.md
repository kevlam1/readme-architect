# sample-app

A tiny todo list page with dark mode.

## What it does

It shows todos and saves them in localStorage.

## Built with

Vite and nanoid.

## Features

- Dark mode.
- Saves todos in localStorage.

## Highlights

- Fast.

## Run it locally

```
npm run dev
npm run test
node scripts/seed.mjs
```

The `node scripts/check-*.mjs` files check the logic.
