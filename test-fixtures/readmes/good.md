# sample-app

A tiny todo list page.

## What it does

It shows a list of todos and saves them in the browser's localStorage. Each todo gets an id from nanoid.

## Features

- Add a todo.
- Todos are saved in `localStorage` under the key `sample-todos`.

## Built with

Vite and nanoid.

## Run it locally

```
npm run dev
npm run build
```
